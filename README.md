アメリカ50州クイズ 学習アプリ

使い方：index.html をブラウザで開いてください。インターネット接続なしで基本機能を利用できます。

機能：
・州の基本情報（位置・地形、主要都市、産業・経済、歴史・文化、観光地）
・4択クイズ、記述式クイズ、地図を見ながら答える州選択クイズ
・州の学習済みマーク、ブラウザ内への学習記録保存

地図について：
依頼者が提供したモノクロのアメリカ州境地図を、HTML内に埋め込んで採用しています。ファイルを別途用意しなくても表示できます。画像の州境を直接クリックして塗り分ける機能は未実装です。州の選択や学習済みマークは、地図の下にある州略号パネルから操作してください。

注意：人口などの数値は概数です。記述式の採点はキーワード照合による簡易判定です。
